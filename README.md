This project is a simple web page that includes a textarea created using HTML and basic JavaScript.
It allows users to type text, but the input cannot exceed 200 characters.
Once the limit is reached, the user won’t be able to type more characters.

It’s a beginner-friendly project to understand:

How to create a textarea in HTML

How to use JavaScript for character limit validation

How to update text dynamically inside the webpage

💡 Features

Simple and clean user interface

Restricts typing beyond 200 characters

Shows live character count

Built using only HTML, CSS, and basic JavaScript

🧩 Technologies Used

HTML: For structure

CSS: For basic styling

JavaScript: For functionality (character limit logic)

🚀 How to Use

Type text in the textarea box.

You’ll see the character count update in real-time.

Once you reach 200 characters, typing will stop automatically.
